# Proyecto Titanic - Despliegue con Streamlit

Este proyecto utiliza **Streamlit** y **NumPy** para visualizar y analizar datos del Titanic.

## Dependencias

- **Streamlit**: 1.44.1
- **NumPy**: 1.24.3

## Ejecución de la Aplicación

Para poder ejecutar la aplicación usando Streamlit, sigue estos pasos:

1. Navega hasta la carpeta `notebooks` ubicada en:
`DataAI-Fundamentos-Aplicaciones/Analitica/proyectos/titanic/notebooks`

2. Una vez dentro de la carpeta, ejecuta el siguiente comando:
```bash
streamlit run 08_titanic_streamlit_despliegue.py
